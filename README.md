# BHub

BHub é um hub pessoal criado para centralizar meus projetos, estudos e anotações em um único lugar.

A plataforma funciona como uma espécie de portfólio e ambiente de aprendizado, reunindo aplicações desenvolvidas, experimentos, conteúdos de estudo e materiais utilizados durante minha evolução na área de tecnologia.

---

## 🚀 Objetivo

O principal objetivo do BHub é organizar meus projetos e estudos de forma prática, moderna e acessível, permitindo acompanhar minha evolução como desenvolvedor.

---

## ✨ Funcionalidades

- Centralização de projetos pessoais
- Área para anotações e estudos
- Organização de conteúdos por categorias
- Interface moderna e responsiva
- Navegação simples e intuitiva
- Estrutura preparada para expansão futura

---
