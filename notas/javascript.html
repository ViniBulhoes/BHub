JavaScript

Anotações principais sobre os mecanismos por trás do JS.

1. Closures

Uma closure é a combinação de uma função com as referências ao estado que a circunda (o ambiente léxico). Em outras palavras, uma closure dá acesso ao escopo de uma função externa a partir de uma função interna.

2. Event Loop

O JavaScript tem um modelo de concorrência baseado em um "event loop", que é responsável por executar o código, coletar e processar eventos, e executar subtarefas em fila.

  • Call Stack: Onde o código é executado.
  • Web APIs: Lida com operações assíncronas (setTimeout, fetch).
  • Task Queue: Fila de callbacks prontos para executar.

3. Promises

Representa a eventual conclusão (ou falha) de uma operação assíncrona e seu valor resultante.

const promessa = new Promise((resolve, reject) => {
    // operação
    if (sucesso) {
        resolve("Deu certo!");
    } else {
        reject("Deu erro!");
    }
});
