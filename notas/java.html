Java Essencial

Linguagem de tipagem estática, forte e totalmente voltada à Programação Orientada a Objetos (POO).

1. Estrutura Básica

Tudo no Java precisa estar dentro de uma Classe. O ponto de entrada principal é o método estático main.

public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}

2. Pilares da POO

  • Encapsulamento: Esconder atributos usando private e expor métodos get/set.
  • Herança: Reutilizar código criando subclasses (extends).
  • Polimorfismo: Tratar objetos de classes derivadas como se fossem da classe base.
  • Abstração: Definir contratos através de interfaces ou classes abstratas.

3. Collections Framework

Interfaces principais para manipulação de grupos de objetos:

// List - Permite duplicatas e mantém ordem
List<String> lista = new ArrayList<>();

// Set - Não permite duplicatas
Set<Integer> conjunto = new HashSet<>();

// Map - Chave/Valor
Map<String, String> mapa = new HashMap<>();
