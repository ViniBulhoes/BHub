Resumo Estruturado de MySQL

MySQL é um Sistema de Gerenciamento de Banco de Dados Relacional (SGBD) utilizado para armazenar, organizar e consultar dados utilizando SQL.

1. Comandos Básicos

Comandos fundamentais para gerenciamento do banco.

-- Criar banco de dados
CREATE DATABASE escola;

-- Selecionar banco
USE escola;

-- Mostrar bancos existentes
SHOW DATABASES;

-- Mostrar tabelas
SHOW TABLES;

-- Excluir banco
DROP DATABASE escola;

2. Como Criar Tabelas

As tabelas armazenam os dados do sistema.

CREATE TABLE alunos (
    id INT PRIMARY KEY AUTO_INCREMENT,
    nome VARCHAR(100),
    idade INT,
    email VARCHAR(150)
);
  • INT: números inteiros.
  • VARCHAR: textos curtos.
  • PRIMARY KEY: identificador único.
  • AUTO_INCREMENT: incremento automático.

3. Como Alimentar Tabelas

Inserção, atualização e remoção de dados.

-- Inserir dados
INSERT INTO alunos (nome, idade, email)
VALUES ('Carlos', 18, 'carlos@gmail.com');

-- Atualizar dados
UPDATE alunos
SET idade = 25
WHERE id = 1;

-- Excluir dados
DELETE FROM alunos
WHERE id = 1;

4. Consultas (SELECT)

Utilizadas para visualizar e filtrar informações.

-- Mostrar todos os dados
SELECT * FROM alunos;

-- Filtrar dados
SELECT * FROM alunos
WHERE idade > 18;

-- Ordenar resultados
SELECT * FROM alunos
ORDER BY nome ASC;

-- Limitar resultados
SELECT * FROM alunos
LIMIT 5;

5. Junção de Tabelas (JOIN)

Usado para relacionar tabelas através de chaves estrangeiras.

SELECT alunos.nome, cursos.nome
FROM alunos
INNER JOIN cursos
ON alunos.curso_id = cursos.id;
  • INNER JOIN: retorna registros relacionados.
  • LEFT JOIN: retorna todos os registros da tabela esquerda.

6. Funções Importantes

Funções utilizadas em análises e relatórios.

-- Contar registros
SELECT COUNT(*) FROM alunos;

-- Média
SELECT AVG(idade) FROM alunos;

-- Maior valor
SELECT MAX(idade) FROM alunos;

-- Menor valor
SELECT MIN(idade) FROM alunos;

7. Filtros e Operadores

Permitem buscas mais específicas.

-- LIKE
SELECT * FROM alunos
WHERE nome LIKE 'A%';

-- IN
SELECT * FROM alunos
WHERE idade IN (18, 20, 22);

-- BETWEEN
SELECT * FROM alunos
WHERE idade BETWEEN 18 AND 25;

8. GROUP BY e HAVING

Utilizados para agrupamento de registros.

SELECT curso_id, COUNT(*) AS total
FROM alunos
GROUP BY curso_id
HAVING total > 5;

9. Dicas da Linguagem

  • Sempre utilize WHERE em UPDATE e DELETE.
  • Use nomes claros nas tabelas e colunas.
  • Evite usar SELECT * em sistemas grandes.
  • Crie índices em colunas frequentemente pesquisadas.
CREATE INDEX idx_email
ON alunos(email);

10. Conceitos Avançados

Views

CREATE VIEW vw_alunos AS
SELECT nome, idade
FROM alunos;

Transactions

START TRANSACTION;

UPDATE contas
SET saldo = saldo - 100
WHERE id = 1;

COMMIT;
