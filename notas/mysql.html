MySQL Avançado

Sistema de Gerenciamento de Banco de Dados Relacional. Base fundamental para arquitetura e persistência de dados consistentes.

1. Comandos Essenciais (CRUD)

-- CREATE
INSERT INTO usuarios (nome, email) VALUES ('Vinícius', 'vini@email.com');

-- READ
SELECT nome, email FROM usuarios WHERE id = 1;

-- UPDATE
UPDATE usuarios SET nome = 'Vini' WHERE id = 1;

-- DELETE
DELETE FROM usuarios WHERE id = 1;

2. Joins Relacionais

Usados para combinar linhas de duas ou mais tabelas baseadas em uma coluna comum.

  • INNER JOIN: Retorna registros que têm valores correspondentes em ambas as tabelas.
  • LEFT JOIN: Retorna todos os registros da tabela da esquerda e os correspondentes da direita.
SELECT usuarios.nome, pedidos.total
FROM usuarios
INNER JOIN pedidos ON usuarios.id = pedidos.usuario_id;

3. Índices (Indexes)

Índices melhoram drasticamente a velocidade das consultas SELECT (mas deixam INSERTs/UPDATEs mais lentos). Use em colunas frequentemente usadas no WHERE.

CREATE INDEX idx_email ON usuarios(email);
