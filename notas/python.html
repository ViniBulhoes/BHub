Python Essencial

Linguagem de alto nível com foco em legibilidade e produtividade. Excelente para automações, análise de dados e backend.

1. Listas e Dicionários

As estruturas de dados mais comuns e versáteis do Python.

# Lista
frutas = ["maçã", "banana", "cereja"]
frutas.append("laranja")

# Dicionário (Key-Value)
pessoa = {
    "nome": "Vinícius",
    "idade": 25,
    "dev": True
}
print(pessoa["nome"])

2. Funções e Tipagem

Python é dinamicamente tipado, mas você pode usar Type Hints para facilitar a leitura e o uso em IDEs.

def saudar(nome: str) -> str:
    return f"Olá, {nome}!"

3. Ambientes Virtuais (VENV)

Sempre use ambientes virtuais para não misturar as bibliotecas dos seus projetos no sistema operacional inteiro.

  • Criar: python -m venv .venv
  • Ativar (Windows): .venv\Scripts\activate
